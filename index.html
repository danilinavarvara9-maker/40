Каждая строка станет отдельным слотом: для неё конструктор соберёт готовый промт для нейросети изображений (вкладка «Картинки») и добавит пункт в промт игры.

🤖 Что попадёт в промт

Блок «6. ИЗОБРАЖЕНИЯ: сгенерируй» + готовый промт для каждой картинки: фон, персонаж, карта, награда, финал, задания и все дополнительные элементы из списка выше. Генерировать — в Qwen, Kandinsky, Шедеврум, Nano Banana.

⬜ Что попадёт в промт

Строка из шаблона: «Изображения: плейсхолдеры с описанием в стиле игры». Плюс требование сделать в левом нижнем углу игры кнопку «＋» — чтобы потом подставить свои картинки и скачать готовую игру с закрытым кодом.

📁 Картинки добавлю позже через Базис24

В промт попадёт: картинки НЕ генерировать, я добавлю их сам через Базис24 / Canva / фотобанк. В самой игре в левом нижнем углу будет плавающая кнопка «＋»: нажали → загрузили файлы или вставили ссылки во все слоты → нажали «Скачать готовую игру» → получили HTML-файл с картинками внутри и закрытым для редактирования кодом.
